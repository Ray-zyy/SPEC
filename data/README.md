# Data layout

Raw hydrological datasets are **not redistributed** in this repository.

The code in this release is configured for **CAMELS-AUS**. The included loader expects the per-basin layout that was used by the supplied experiment archive:

```text
$SPEC_DATA/
├── CAMELS-AUS/
│   ├── forcing/
│   │   ├── <basin>.csv      # date, prcp, srad, tmax, tmin, vprp, aet, pet
│   │   └── ...
│   └── runoff/
│       ├── <basin>.csv      # date, runoff
│       └── ...
└── processed/               # generated by scripts/prepare_data.py
```

Set the data root explicitly if it is outside the repository:

```bash
export SPEC_DATA=/path/to/spec_data
python scripts/prepare_data.py
```

The source archive documents CAMELS-AUS v1 using the following official entries:

- Data archive: https://doi.org/10.5281/zenodo.4784634
- Dataset paper: https://doi.org/10.5194/essd-13-3847-2021

> **Important:** the supplied code archive does not include a converter from the original Zenodo wide-table files to the per-basin `forcing/` + `runoff/` layout above. If your CAMELS-AUS download is still in its original release layout, convert it to this structure before running `prepare_data.py`.
